🚀 What Is hostwarden?

If you run one or more ESXi servers on their own — without a big management platform behind them — you already know the problem. Each machine has its own login page, its own dashboard, and its own way of showing you what is going on. Checking the health of three hosts means opening three browser tabs and remembering three sets of details.

hostwarden fixes that. It is a web console that runs in your own browser and brings your standalone ESXi hosts together under one roof. You open a single page, and you can see your hosts, switch between them, and work with them from one consistent screen instead of jumping around.

It is completely open source, which means the code is publicly available, anyone can inspect it, and there are no licence fees, subscriptions, or hidden costs. You download it, you run it, you use it.

✨ What You Can Expect

hostwarden is built around a simple idea: one window for all your hosts. Here is what that looks like in practice.

  • One place for every host. Add each of your standalone ESXi machines once, and reach them all from the same console from then on.
  • A clear overview. See which hosts are connected and reachable at a glance, instead of guessing.
  • Quick switching. Move from one host to another without retyping addresses or hunting for bookmarks.
  • Runs in your browser. There is no separate app window to learn — the console is a web page served from your own machine or network.
  • No lock-in. Because it is open source, you are never tied to a vendor or a paid plan.

Because hostwarden is a young project, the exact set of tools grows over time. The download page below always points to the newest build, so you are never stuck on an old copy.

🖥️ Before You Begin

To get the most out of hostwarden, have a few basics ready before you start:

  • A Windows computer running Windows 10 or Windows 11, with at least 4 GB of memory and a couple of gigabytes of free disk space.
  • A modern browser such as Microsoft Edge, Google Chrome, or Mozilla Firefox.
  • The network address of each ESXi host you want to manage, and the login details for those hosts.
  • A network connection from your Windows computer to your ESXi hosts — the same network you would normally use to reach them.

You do not need to know how to program, use a command line, or read code. If you can fill in a form and click a button, you can use hostwarden.

🧭 Your First Five Minutes

Open the console. Once hostwarden is running, your browser will show the main page. This is your starting point every time.

Add your first host. Look for the option to add or connect a host. You will be asked for the address of the machine and its login details — the same ones you would use to reach that host directly.

Repeat for the rest. Add each of your standalone ESXi hosts the same way. The list grows as you go, and every host you add stays available in the console.

Use the list to move around. From now on, switching between hosts is a click rather than a new tab with a typed-in address.

Close and come back. You can shut the browser tab whenever you like and return to the same bookmarked page later.

🛠️ Common Questions

Is hostwarden free? Yes. It is open-source software, available at no cost through the link on this page.

Does it work without internet access? The download requires an internet connection, but once hostwarden is on your machine it works over your own local network to reach your hosts.

Will it change anything on my ESXi hosts? hostwarden is a management console — it gives you a window into your hosts rather than replacing them. Your existing setup stays as it is.

What if a host does not appear? Double-check the address you entered and make sure your Windows computer can reach that host from a normal browser. If the host's own page will not load, hostwarden will not be able to reach it either.

Can I use more than one host? Yes — bringing multiple standalone ESXi hosts together is exactly what hostwarden is built for.

How do I get the newest version? Return to the download link and grab the latest release. Because the project is actively maintained, new builds appear there over time.
